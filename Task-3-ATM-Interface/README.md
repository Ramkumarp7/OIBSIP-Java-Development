# Task 3 - ATM Interface

**Internship:** Oasis Infobyte - Java Development

A Java-based ATM simulation with a graphical banking interface.

## Features
- Account balance management
- Deposits and withdrawals
- Money transfers
- PIN verification
- Daily withdrawal limit
- Transaction history
- Receipt export

## Technologies
- Java
- Java Swing
- Object-Oriented Programming
- IntelliJ IDEA
