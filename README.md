Welcome to my **Java Development Internship Projects** repository! This repository contains the Java applications I developed as part of my internship at **Oasis Infobyte**.

## 📂 Projects

### 🎮 Task 2 – Number Guessing Game
A Java Swing-based interactive number guessing game with multiple difficulty levels and dynamic gameplay.

**Features:**
- Easy, Medium and Hard difficulty levels
- Random number generation
- Dynamic range narrowing
- Hot, Warm and Cold proximity hints
- Guess history and attempt tracking
- Points, difficulty multipliers and win streaks
- Custom-designed desktop interface

**Technologies:** Java, Java Swing, Maven

[View Task 2 – Number Guessing Game](./Task-2-Number-Guessing-Game/)

### 🏦 Task 3 – ATM Interface
A Java-based ATM simulation featuring a graphical banking interface and transaction management.

**Features:**
- Account balance management
- Deposits and withdrawals
- Money transfers
- PIN verification
- Daily withdrawal limit
- Transaction history
- Receipt export

**Technologies:** Java, Java Swing, Object-Oriented Programming

[View Task 3 – ATM Interface](./Task-3-ATM-Interface/)

### 📝 Task 4 – Online Examination System
A Java Swing desktop application designed to provide an interactive examination experience.

**Features:**
- Login and examination interface
- Multiple-choice questions
- Answer selection and navigation
- Examination submission
- Result calculation
- Interactive dashboard

**Technologies:** Java, Java Swing, Maven

[View Task 4 – Online Examination System](./Task-4-Online-Examination-System/)
