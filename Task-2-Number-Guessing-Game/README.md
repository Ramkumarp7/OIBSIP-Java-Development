# Task 2 - Number Guessing Game

**Internship:** Oasis Infobyte - Java Development

A Java Swing desktop application featuring a number guessing game with three difficulty levels.

## Features
- Easy, Medium and Hard modes
- Random number generation
- Limited attempts
- Dynamic range narrowing
- Hot, Warm and Cold hints
- Guess history
- Points and win streak tracking
- Custom Cards Against Humanity-inspired UI

## Technologies
- Java
- Java Swing
- Maven
- IntelliJ IDEA
